# Функции по ролям

> Полная матрица ролей и разделов личного кабинета — **`docs/roles-matrix.md`**.
> Этот файл — краткая таблица для быстрой справки.

Бот работает в режиме «только web»: команды-боты устарели, основной интерфейс —
Mini App (web-кабинет). Ниже — разделы кабинета по ролям.

## Роли

| Роль | Разделы ЛК | Ключевые действия |
|------|-----------|-------------------|
| **Пользователь** | Главная (публичная лента), Мои билеты, Профиль (минимальный) | купить/вернуть билет, показать QR, «Стать организатором» |
| **Организатор без группы** | Мои мероприятия, Продажи/Вход, Мои площадки, Профиль | создаёт/публикует/редактирует/удаляет, продажи, статистика, проверка на входе, пригласительные/QR/promo/цены (по тарифу) |
| **Организатор с группой** | то же + бейдж «Площадка подключена» | то же + площадки в профиле (бесшовный переход из «без группы») |
| **Супер-админ** | Панель: подписки организаторов (ТГ+ВК), статистика, рассылка, здоровье | поиск покупателя по коду/QR → подписать/отписать, stats, broadcast, health |

## Механизм проверки ролей (web)

- **Пользователь** — без проверок (открытые эндпоинты: лента, покупка, билеты).
- **Организатор** — подписка пользователя ИЛИ канал с активной подпиской
  (`is_creator`). Только организатор создаёт мероприятия.
- **Супер-админ** — `ADMIN_TELEGRAM_IDS` (`role=super_admin`). Эксклюзивен:
  не управляет мероприятиями, каналами и площадками организаторов.
