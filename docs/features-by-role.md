# Функции участников процесса

## Роли
- **Пользователь** — любой Telegram пользователь, написавший боту
- **Админ канала** — пользователь в таблице `channel_admins` канала с активной подпиской
- **Супер-админ** — Telegram ID в `ADMIN_TELEGRAM_IDS`

## Inline-кнопки

### В канале (анонс)
- 🎟 **Купить** — всем пользователям (покупка в 1 клик)

### В ЛС (админ-панель `/admin`)
**Для всех админов:** 🎫 Создать мероприятие, 📋 Мои мероприятия, 🔄 Репост анонсов, 📢 Мои каналы
**Только супер-админу:** 📊 Общая статистика, 🔍 Проверить подписки, 📋 Список каналов, ℹ️ Инфо о канале, 👥 Инфо о пользователе, 🟢 Подписать, 🔴 Отписать, 🔄 Сменить админа, 📢 Рассылка, 🩺 Здоровье, ✅ Отменить билет

### Панель управления мероприятием (в ЛС)
- 📊 Статистика — ⏸ Вкл/Откл — 🔄 Репост — ❌ Закрыть

| Роль | Команды в меню |

| Пользователь | `/start`, `/events`, `/event`, `/buy`, `/my_tickets`, `/cancel` |
| Админ канала | + `/admin`, `/create_event`, `/events_all`, `/deactivate`, `/activate`, `/stats`, `/repost_events`, `/my_channels` |
| Супер-админ | + `/subscribe`, `/unsubscribe`, `/stats_all`, `/list_channels`, `/channel_info`, `/user_info`, `/admin_cancel`, `/broadcast`, `/health`, `/check_expired`, `/change_admin` |

## Механизм проверки ролей

- **Пользователь** — без проверок (открытые команды)
- **Админ канала** — `_get_admin_channel()` → `ChannelAdminService.user_is_admin()` → Telegram API `getChatMember` → `is_subscription_valid()`
- **Супер-админ** — `ADMIN_TELEGRAM_IDS` → `_is_super_admin()`
