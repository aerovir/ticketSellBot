# Журнал ручного тестирования TicketBot

Формат записи:
- **Дата / время:** когда проводилось
- **Среда:** где (прод VPS / локально) и что запущено
- **Пункты плана:** какие разделы `docs/test-plan-manual.md` проверялись
- **Результат:** ✅ прошло / ❌ не прошло / ⚠️ замечание
- **Что не удалось протестировать:** и почему

Актуальный чек-лист — в `docs/test-plan-manual.md`. Здесь фиксируются результаты.
