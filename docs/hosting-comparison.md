# Хостинги для TicketBot — сравнение

## 🏆 Сравнение хостингов с посуточной/почасовой оплатой

### 1. Aeza — Москва, есть почасовая

| Параметр | Значение |
|---------|----------|
| **CPU** | 1 vCPU (AMD Ryzen 9) |
| **RAM** | 2 GB |
| **Диск** | 30 GB NVMe |
| **Трафик** | Безлимитный |
| **Порт** | 25 Gbps |
| **Оплата** | **Почасовая: от €0.018/час** (~1.8 ₽/час по курсу) |
| **В месяц (24/7)** | **~€4.94/мес** (~500 ₽) |
| **Дата-центр** | Москва |

**Особенности:**
- ✅ Почасовая оплата — платите только за часы работы
- ✅ Мгновенная активация
- ✅ Root-доступ
- ✅ Российский дата-центр (Москва)

**Для теста:** Запустить на час — ~1.8 ₽. На день — ~43 ₽. Ниже порог входа.

👉 [aeza.net](https://aeza.net)

### 2. LightNode — Москва, почасовая (Pay-as-you-go)

| Параметр | Значение |
|---------|----------|
| **CPU** | 1 vCPU (High Frequency) |
| **RAM** | 2 GB DDR4 |
| **Диск** | 50 GB NVMe |
| **Трафик** | 1 TB |
| **Порт** | 1 Gbps |
| **Оплата** | **$0.012/час** (~1 ₽/час) |
| **В месяц (24/7)** | **~$7.71/мес** (~620 ₽) |
| **Дата-центр** | Москва |

**Особенности:**
- ✅ Самая низкая почасовая ставка
- ✅ Без контракта, отмена в любой момент
- ✅ Бесплатная смена IP
- ✅ Бонус до $15 при первом пополнении

**Для теста:** 1 ₽/час — можно гонять тесты часами за копейки.

👉 [lightnode.com](https://go.lightnode.com/russia-vds)
