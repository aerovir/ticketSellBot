1. Убедись, что есть **два канала**, где бот — админ
2. Убедись, что super-admin (ты) имеет доступ к `/admin`

## 2. Бесплатное мероприятие на Basic

### 2.1 Создать бесплатное мероприятие на Basic-канале
В ЛС с ботом:
```
/admin → 🎫 Создать мероприятие
→ Название: Бесплатная лекция
→ Описание: Вход свободный
→ Дата: {будущая дата}
→ Место: Москва
→ Цена: 0
→ Количество билетов: 50
→ Афиша: пропустить
→ Подтвердить
```
**Ожидание:** ✅ Мероприятие создано (черновик)

### 2.2 Опубликовать
```
/admin → 📋 Мои мероприятия → кнопка управления → 📢 Опубликовать
```
**Ожидание:** анонс ушёл в канал с кнопкой «🎟 Получить билет»

### 2.3 Попытка создать платное на Basic (негативный тест)
```
/admin → 🎫 Создать мероприятие (на Basic-канале)
→ Цена: 500
```
**Ожидание:** ❌ Ошибка «Ваш тариф поддерживает только бесплатные»

## 4. Покупка билетов и коды

### 4.1 Купить билет на бесплатное
Нажать «🎟 Получить билет» в анонсе
**Ожидание:** алерт с кодом вида `✅ Билет! Код: AB3X-K7M9`

### 4.2 Купить билет на платное
Нажать «🎟 Купить» в анонсе
**Ожидание:** алерт с кодом `✅ Билет! Код: XXXX-XXXX`

### 4.3 Проверить /my_tickets
Написать `/my_tickets`
**Ожидание:** список билетов, у каждого — 🔑 Код

## 5. Вход (валидация билетов)

### 5.1 Успешный вход по коду
Как админ канала (или super-admin):
```
/check AB3X-K7M9
```
**Ожидание:** ✅ Вход разрешён! Иван И., мероприятие «Название», время

### 5.2 Повторный вход (негативный)
```
/check AB3X-K7M9
```
**Ожидание:** 🟡 Билет уже использован, первый вход {время}

### 5.3 Неверный код
```
/check ZZZZ-ZZZZ
```
**Ожидание:** ❌ Билет с кодом ZZZZ-ZZZZ не найден

### 5.4 Код без дефиса
```
/check AB3XK7M9
```
**Ожидание:** ✅ Вход разрешён (нормализация кода)

### 5.5 Проверить как обычный пользователь (негативный)
Пользователь без админ-прав пишет `/check AB3X-K7M9`
**Ожидание:** ❌ У вас нет доступа к проверке билетов.
