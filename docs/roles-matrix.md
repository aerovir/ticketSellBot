# Матрица ролей личного кабинета

**Дата:** 2026-08-19
**Назначение:** единый источник правды «роль → разделы кабинета → действия → запреты». Основывает логику web-кабинета (Mini App) и прав доступа. Код реструктуризуется под эту матрицу.

---

## Роли

| Роль | Определение (backend) | Разделы ЛК | Ключевые действия | Запрещено |
|------|----------------------|-----------|-------------------|-----------|
| **Пользователь** | нет подписки, нет канала с подпиской, нет VK-группы; `role=user` | Главная (публичная лента), Мои билеты, Профиль (минимальный) | купить билет, вернуть билет, показать QR на входе, «Стать организатором» → `POST /me/subscription` | создание мероприятий, каналы, VK-группы, привязка, проверка билета |
| **Организатор без группы** | активная подписка (пользователя или канала), нет площадки; `role=organizer`, `has_group=false` | Главная (мои мероприятия), Продажи/Вход, Мои площадки, Профиль | создаёт/редактирует/публикует/удаляет мероприятия, продажи, статистика, проверка на входе, пригласительные/QR/promo/price-ranges (по тарифу), добавить площадку | — |
| **Организатор с группой** | то же + есть площадка (TG-канал с активной подпиской ИЛИ VK-группа); `has_group=true` | то же + бейдж «Площадка подключена», площадки в профиле | то же; бесшовный переход из «без группы» | — |
| **Супер-админ** | `ADMIN_TELEGRAM_IDS`; `role=super_admin` | Главная → «Панель» (глобальная): **управление подписками организаторов (ТГ+ВК)**, статистика, рассылка, здоровье | добавить/удалить организатора, включить/выключить подписку (для ТГ и ВК), найти покупателя по коду/QR → подписать/отписать, stats, broadcast, health | **НЕ управляет каналами, мероприятиями и площадками организаторов; НЕ показывает список всех пользователей** |

---

## Ключевые решения

1. **Эксклюзивность супер-админа**: даже если суперадмин имеет подписку/канал, `role=super_admin` приоритетен → он не получает организаторский раздел в веб-кабинете. Не управляет мероприятиями и площадками организаторов.
2. **`has_group`** = есть TG-канал с **активной подпиской** (`managed_channel_ids`) ИЛИ **VK-группа** (self-service). Влияет только на отображение/подтверждение, не на права (организатор и так может управлять площадкой).
3. **Бесшовный переход**: организатор без группы добавляет канал/VK → становится «с группой» (без повторной регистрации). Групп может быть несколько. Прав не меняет.
4. **Стать организатором**: пользователь → кнопка «Стать организатором» → покупка подписки (`POST /me/subscription`). Без подписки создание недоступно.
5. **Только организатор создаёт** мероприятия (открытое создание у user недоступно).
6. **Минимальный ЛК пользователя**: билеты (купить/вернуть/QR), без админ-разделов.
7. **Супер-админ не показывает список пользователей** — вместо него поиск покупателя по коду/QR билета и управление подпиской из карточки.
8. **Платформы**: пользователи ТГ и ВК — единая БД (канон-пользователь, линковка TG↔VK). Суперадмин управляет подписками для обеих платформ.

## Пользователь: активности

У пользователя две активности: **купить билет** или **вернуть билет**, плюс **показать билет на входе** (код/QR). Личный кабинет минимальный: лента мероприятий → покупка → «Мои билеты» (код/QR, возврат). Админ-разделы скрыты. Кнопка «Стать организатором» ведёт к покупке подписки.

## Организатор: без группы → с группой (бесшовный переход)

Организатор без группы работает в Mini App (подписка на пользователя). Добавив площадку (TG-канал с подпиской или VK-группу), он становится организатором **с группой** — права те же, меняется отображение (бейдж «Площадка подключена») и площадки видны в профиле. Групп может быть несколько.

## Супер-админ: управление подписками организаторов

- **Добавить организатора** — найти покупателя по коду/QR (или платформа+ID) → выдать подписку.
- **Удалить организатора** — деактивировать подписку.
- **Включить/выключить подписку** — активация/деактивация (для ТГ и ВК).
- **Поиск покупателя по коду/QR** — вводит код билета → карточка (имя, платформа, мероприятие, статус) → оттуда управление подпиской.
- **НЕ** показывает список всех пользователей, **НЕ** управляет каналами/мероприятиями/площадками.
