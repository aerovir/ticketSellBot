# Telegram Bot

Адаптер для Telegram на базе **aiogram 3.x**.

## Статус

✅ **Работает** — используется в продакшене.

## UX: всё в канале

Все действия пользователя — через inline-кнопки в канале. Переход в личные сообщения не требуется.

### 📢 В канале — анонсы с inline-кнопками

Каждое мероприятие публикуется в канале с тремя кнопками:

| Кнопка | Действие |
|--------|----------|
| 🎟 Купить | Покупка билета — результат в всплывающем окне |
| 🎫 Мои билеты | Список билетов отправляется в ЛС (или подсказка, если диалог не начат) |
| 📋 Все мероприятия | Список мероприятий отправляется в ЛС |

Текстовые команды в канале (альтернатива кнопкам):
| Команда | Описание |
|---------|----------|
| `/events` | Список предстоящих мероприятий |
| `/event <id>` | Детали мероприятия |

### 💬 В личных сообщениях (только для админов)
| Команда | Описание |
|---------|----------|
| `/start` | Приветствие |
| `/admin` | Меню администратора |
| `/create_event` | Пошаговое создание мероприятия (FSM) |
| `/events_all` | Все мероприятия |
| `/stats <id>` | Статистика продаж |
| `/deactivate <id>` | Отключить мероприятие |
| `/activate <id>` | Включить мероприятие |
| `/repost_events` | Перепостить анонсы в канал |
| `/my_channels` | Мои каналы и статус подписки |
| `/subscribe <user_id> <days>` | Активировать подписку (super-admin) |

Обычные пользователи могут не писать боту в ЛС — все действия доступны через кнопки в канале. Если пользователь не начинал диалог, при нажатии на кнопки «Мои билеты» или «Все мероприятия» бот подскажет написать /start.

### Подписка (multi-tenant)

Каждый канал изолирован:
1. Админ оплачивает подписку → super-admin активирует через `/subscribe`
2. Админ добавляет бота в канал → бот проверяет подписку
3. Админ создаёт свои мероприятия → они видны только в его канале
4. Пользователи канала покупают билеты только этого канала

## Настройка

1. Создать бота через [@BotFather](https://t.me/BotFather) → получить токен
2. Настроить `.env.telegram`:
   ```
   DATABASE_URL=postgresql+asyncpg://tg_user:password@localhost:5432/ticketbot
   TELEGRAM_TOKEN=ваш_токен
   ADMIN_TELEGRAM_IDS=123456,789012
   ```

### Telegram канал для анонсов

1. Создать канал (приватный или публичный)
2. Добавить бота в канал как **администратора** с правами:
   - ✅ Отправлять сообщения
   - ✅ Читать сообщения
3. Отключить Privacy Mode в BotFather:
   ```
   @BotFather → /mybots → Bot → Bot Settings → Group Privacy → Turn off
   ```
4. Канал привязывается к боту автоматически при добавлении (проверяется подписка)

### Классы

- **`TelegramBot`** (`bot.py`) — основной класс с хендлерами
- **`ChannelManager`** (`channel.py`) — отправка анонсов в канал
- **`CreateEvent`** — FSM для пошагового создания мероприятия
