# VK Bot

Адаптер для VK (ВКонтакте) на базе **vkbottle 4.x**.

## Статус

⏸️ **Отключён** — код готов, но не запущен в продакшене.  
Ждёт настройки группы и токена.

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие + список команд |
| `/events` | Список предстоящих мероприятий |
| `/event <id>` | Детали мероприятия |
| `/buy <id>` | Купить билет |
| `/my_tickets` | Мои билеты |
| `/cancel <id>` | Отменить билет |

> **Примечание:** Админ-команды для VK не реализованы. Для управления мероприятиями используйте Telegram админку.

## Настройка

1. Создать или использовать существующее сообщество ВК
2. Получить токен сообщества с правами на сообщения
3. Настроить `.env.vk`:
   ```
   DATABASE_URL=postgresql+asyncpg://vk_user:password@localhost:5432/ticketbot
   VK_TOKEN=ваш_токен_сообщества
   VK_GROUP_ID=id_группы
   ```

## Запуск

```bash
docker compose --profile all up -d vk
```

## Отличия от Telegram

- Нет inline-кнопок (VK не поддерживает)
- Нет админ-панели
- Нет канала для анонсов
- Покупатель в VK не дублируется в Telegram (единая БД, но разные User)
